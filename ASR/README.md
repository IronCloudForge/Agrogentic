# ASR — Architecturally-Significant Requirements

This folder holds the Architecturally-Significant Requirements (ASRs) for this project's agentic AI governance architecture — one file per requirement, plus `ASR-Log.md` (the authoritative index of every ASR's current status) and `ASR-Template.md` (the template for drafting a new one). See `Layer-Model.md` for what an ASR is and how it fits the four-layer model.

## Disclaimer

This folder is part of an independent, volunteer-run open-source research project. It is not sponsored, reviewed, sanctioned, or endorsed by the U.S. Department of Agriculture or any federal agency, and nothing in it represents official USDA policy, guidance, or an authorized architecture.

The `Status` field on every ASR and ADR in this folder — including any marked `Accepted` — reflects this project's own internal drafting workflow, not a federal authorization decision. Per the four-layer model this repository follows (`Layer-Model.md`), documents in this folder are Layer 2: the working layer where requirements are stated and decisions are recorded. Only Layer 1 — a signed instrument from an actual authorizing official — carries real authorizing weight, and no such instrument exists for anything in this repository. Treat every document here as a research contribution to be evaluated on its merits, not as guidance to be followed.

For the current status of any specific requirement or decision, see `ASR-Log.md` / `ADR-Log.md` rather than assuming this note is current.
