# Knowledge Sources

Local archive of the Layer 3 sources catalogued in `Knowledge-Source-References.md`, organized by the same credibility tier used there. This directory holds the actual content — downloaded files where the source's own hosting allowed it, full-text markdown extractions where it didn't — so every `Corpus evidence` citation in an ASR can be checked against a local copy, not just a live external link that may move or disappear.

| Directory | Tier | Sources |
|---|---|---|
| [`Tier-1/`](./Tier-1/) | Institutional or vendor-backed; citable in official work | 7 |
| [`Tier-2/`](./Tier-2/) | Credible research or production evidence; cite as evidence, not as a standard | 5 |
| `Tier-3/` | Unverified or low institutional confidence; do not cite without independent verification | Reserved — not yet built out |

Each tier folder has its own `README.md` index. Each individual source file states its extraction method, pull date, and any caveats in its own footer.

## Keeping this in sync with the catalog

`Knowledge-Source-References.md` is the authoritative catalog — its tier assignments and "what it contributes" descriptions govern. This directory is a convenience archive of that catalog's content, not a parallel source of truth. When a source's tier changes in the catalog, move its file here to match; when a source is added or removed there, add or remove it here in the same contribution.
